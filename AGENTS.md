# Meridian contributor entry point

- Write code, comments and documentation in English, with British spelling.
- Edit `tokens/meridian.tokens.json`, never `css/meridian.css` or `src/tokens.js`. Run `npm run build` and `npm test` before committing.
- A value or component that fails a check ships as Preview, not stable.
- Follow `docs/decisions.md`. If a request conflicts with a decision there, raise the conflict instead of choosing silently.
- Work reversibly. Figma changes, publication and changes to consuming products need their own approval.
