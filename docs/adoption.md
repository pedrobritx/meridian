# Product purpose and theme provenance

Reviewed through GitHub on 8 October 2026 and implemented in the shared Meridian Figma library and reference repository.

| Project | Purpose and profile | Colour, type and symbols | Repository evidence |
| --- | --- | --- | --- |
| Verbalis | Local-first CAT tool · **Parallel** | Retain cyan, warm light grounds and charcoal dark. Geist UI, Geist Mono terminology/code. Paired source/target segments, memory and glossary metaphors. Solid editing cells; glass only in peripheral controls. Preserve the existing V brand mark. | [tokens](https://github.com/pedrobritx/verbalis/blob/main/src/styles/tokens.css), [architecture](https://github.com/pedrobritx/verbalis/blob/main/docs/architecture.md) |
| NotUX | Interactive teaching whiteboard · **Canvas** | Blue selection and amber alignment. SF/system font at runtime; Inter is the portable specimen. Pen, selection, layers and PDF annotation. Separate UI chrome from author-controlled ink and canvas content; opaque inspectors, optional glass docks. | [design system](https://github.com/pedrobritx/NotUX/blob/main/docs/redesign/03-design-system.md), [UI styles](https://github.com/pedrobritx/NotUX/blob/main/packages/ui/src/styles.css) |
| Lexis | ESL learning platform · **Paper** | Preserve sand paper, wine focus and restrained decorative gold. Fraunces headings, Newsreader passages and JetBrains Mono labels. Book, listening and contextual practice; evidence of learning. Opaque lesson and assessment surfaces. | [design](https://github.com/pedrobritx/lexis/blob/main/docs/design.md), [architecture](https://github.com/pedrobritx/lexis/blob/main/docs/architecture.md) |
| Framio | Online museum · **Gallery** | Stone walls, quiet charcoal and restrained brass. Cormorant Garamond headings, Inter UI/attribution. A frame/mat, curation and exhibition metaphors. Preserve artwork, artist, museum and licence colours/details; no blur over artwork. One brass emphasis per production view. | [branding](https://github.com/pedrobritx/framio/blob/main/docs/BRANDING.md), [tokens](https://github.com/pedrobritx/framio/blob/main/styles/tokens.css) |
| Ambientis | Environmental compliance platform · **Grass / Terra proposal** | Pine and mint, readable technical UI. Leaf for orientation, document for evidence, droplet for water, arrows for reconciliation. PT-BR task labels. Pending review and divergence have explicit words/icons; green cannot certify compliance by itself. | [UX](https://github.com/pedrobritx/ambientis/blob/main/docs/product/ux.md), [vision](https://github.com/pedrobritx/ambientis/blob/main/docs/product/vision.md) |

Ambientis is currently a documented foundation. The green mapping is a new proposal, not a claim of an existing production palette or certification. NotUX user drawings, museum artwork and Lexis learner content remain separate from interface theme tokens.

Accessible derivatives preserve the project pigment: Parallel uses darker cyan for text/focus while retaining its existing cyan action fill; Canvas uses a darker blue for small action text and white-labelled actions while retaining source selection blue; Gallery uses #656158 muted text and #765E3C secondary/link text over stone while retaining #7D6440 primary brass. Gold and amber decoration do not become small-text colours.

The [machine-readable profile record](../design/meridian/project-themes.json) contains purposes, typography, synthetic tasks, source paths and palette choices. [Figma specimens](https://www.figma.com/design/aJ2f6aYX9KBucAdPsCmkXn/Meridian?node-id=162-58) show all five projects in light and dark. These comparison rows display primary/glass/opaque alternatives together; a production view chooses the suitable action treatment.

The saved changes live in **pedrobritx/meridian**, the Figma file’s documented sync destination. Theme adoption into each project’s application should preserve its data model, source brand marks, content colours and business semantics. Prior EFL Lesson Framework and VIA references remain historical examples; no new themes are guessed from their names.
