# Meridian 1.0 token migration (phase 3, 2026-11-02)

- **Decision:** ADR-0002 §6 (DECIDED). Environment × Appearance is the only public colour API, 0.5 names stay as deprecated aliases, and product themes move to their products.
- **Machine-readable table:** `design/meridian/deprecations.json`.
- **Status:** PROPOSED details within the decided direction. Nothing is removed or renamed in this phase: every 0.5 selector and custom property keeps working.

## Deprecation table

| 0.5 use | 1.0 replacement | Compatibility |
| --- | --- | --- |
| `[data-meridian]` (Grass, the default) | `[data-meridian][data-meridian-environment="forest"]` | Identical colours (tested) |
| `[data-meridian="paper"]` | `data-meridian-environment="desert"` | Identical colours (tested) |
| `[data-meridian="core"]` | `data-meridian-environment="core"` | Identical except glass alpha: 0.96 in Core 0.5, 0.72 in Dawn and 0.82 in Dusk for the environment (tested) |
| `[data-meridian="parallel"]`, `"canvas"`, `"gallery"` | The product owns its theme: Verbalis, NotUX, Framio (`docs/theming.md`) | Unchanged until removal |
| `--meridian-*` properties (`generated/meridian.css`) | `--md-*` properties (`styles/tokens.css`, `styles/living-environments.css`) | Same values. The website and components already use only `--md-*` |
| Figma Meridian / Colour and Project Colour | Meridian / Environment with Meridian / Appearance | Kept in the library, labelled deprecated |
| Figma Living Environments · 0.6 and 0.6 Lab / Forest | Meridian / Environment, or the lab file | PROPOSED: move to the lab file with the Archive |

**Deprecation window** (`design/meridian/governance.md`): at least two minor releases or 30 days, whichever is longer. Removal only in a major release, so not before 2.0.

## Checks added

- **0.5 contrast in CI:** `tests/token-contrast.test.mjs` requires all 864 contrast pairs of the twelve 0.5 appearances to pass. The committed evidence (`design/meridian/contrast-report.json`) must be reproducible from `tokens.json`. The calculation moved to `scripts/figma/contrast.mjs`; `scripts/build-contrast-report.mjs` still writes the report.
- **Core alias:** a test now requires the Core environment to keep Core 0.5's colour roles, apart from the documented glass alpha. This sits alongside the existing Forest equals Grass and Desert equals Paper tests.
- **Product themes:** `docs/theming.md` describes the method that stays in Meridian:
  - the 39 roles in Dawn and Dusk;
  - the 72-pair contrast check per appearance;
  - `--md-*` output under the product's own attribute.

## Open decision

Profiles carry more than colour. Grass and Paper also set typography, shape and motion; Paper, for example, sets Newsreader, JetBrains Mono and 14 px small corners. The 1.0 decisions cover colour only.

**Your decision:** which profile's typography, shape and motion becomes Meridian's 1.0 default?

My recommendation is **Core**, the neutral profile. Grass's 24 px contours and Paper's editorial type would then move to the products they serve, Paper to Lexis. Until you decide, nothing changes.
