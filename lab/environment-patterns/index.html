ENVIRONMENT PATTERNS 0.6 · Lab

One interface, many kinds of light.

Every specimen on this page is the same shared Meridian fixture: Button, Text Field, Card, Alert, Badge and a segmented control from the stable recipes. Only the boundary attributes change. Environment, Appearance, Product identity, Material and Motion are independent settings, and accessibility requests override all of them.

  • Existing versioned in this repository (tokens, generated environment CSS, component recipes)
  • Proposed resolution model, identity validation, material and motion grammar
  • Lab not approved for production; manual accessibility and device evidence outstanding

Forest first Current candidates

Forest reproduces the approved Grass colours exactly. Dawn is canopy daylight; Dusk is filtered twilight, not black. Same DOM, same states, same geometry.

Resolve a context Proposed
